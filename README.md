# 항만 구조물 점검 시스템 (Port Inspection System)

ESP32와 각종 센서를 활용해 항만 구조물의 상태를 점검하는 프로젝트입니다.  
웹 대시보드로 실시간 데이터를 확인하고, 원격으로 모터를 제어할 수 있습니다.

## 🛠 주요 기능 (Modules)

- **네트워크 (Network)**  
  WiFi에 연결해 센서 데이터를 서버로 보내고, 웹에서 내린 명령을 받아옵니다. 끊기면 스스로 재접속합니다.

- **DC 모터 제어 (DCMotor)**  
  점검 장치를 정방향/역방향으로 움직입니다. 리밋 스위치가 있어서 끝에 닿으면 멈추고, 손으로 직접 돌리면 알아서 인식합니다.

- **수질 센서 (EC Sensor)**  
  물의 전기 전도도(EC)를 측정해 수질이 어떤지 파악합니다.

- **온도 센서 (DS18B20)**  
  현재 수온을 0.5초 간격으로 측정해 알려줍니다.

- **웹 대시보드 (Web UI)**  
  현재 온도랑 EC 값을 그래프나 숫자로 보여주고, 버튼 하나로 점검을 시작하거나 멈출 수 있습니다.

## 🚀 사용법

1. **Modules/** 폴더에 있는 라이브러리들을 모아 `mergeyard.ino`를 업로드하면 됩니다.
2. 같은 네트워크에서 `MockServer`를 실행(`node server.js`)하면 웹으로 모니터링 가능합니다.
